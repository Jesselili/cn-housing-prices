# 房价趋势摘要表设计

## 目标

在趋势看板下方增加一张动态摘要表，复用用户在上方看板选择的住宅类型、城市和日期范围。表格以日期范围起始月份为基期，展示每条目标趋势的最新原始指标和相对基期的累计涨幅。

## 用户可见结果

表格包含以下列：

1. 城市
2. 最新月份
3. 环比（上月=100）
4. 同比（去年同月=100）
5. 相比基期涨幅（动态显示基期月份）

行粒度固定为“城市 × 户型”：

- 二手住宅使用 `size_band=全部`，每个城市一行。
- 新建商品住宅使用 `90m2及以下`、`90-144m2`、`144m2以上`，每个城市三行。
- 新建住宅的城市列显示可读户型文案，例如“北京 · 90m²及以下”；内部 CSV 值继续使用原始 `m2` 字段。

## 数据口径

摘要表与趋势图使用同一份 CSV，但不能把累计趋势值直接作为环比或同比展示。

- 环比读取 `metric=环比` 且 `base=上月=100` 的原始 `value`。
- 同比读取 `metric=同比` 且 `base=上年同月=100` 的原始 `value`。
- 最新月份取该行在当前日期筛选区间内最新的有效环比记录。
- 当前筛选区间包含起始和结束月份；没有显式起始/结束值时，分别使用当前住宅类型和城市口径的首个/最后一个有效月份。
- 相比基期涨幅从该行在区间内的首个有效环比月份开始，将后续月度环比指数连乘；结果为 `(累计指数 - 100)%`。
- 表头中的基期月份使用实际基期字符串，例如 `相比基期涨幅（2023-08）`；如果用户选择 `2025-06`，表头同步显示 `2025-06`。
- 环比、同比显示 1 位小数；基期涨幅显示 2 位小数并带 `%`。
- 缺少对应上月、去年同月或无法计算基期涨幅时显示 `—`，不使用临近月份猜测。

## 架构

### `src/data.ts`

新增独立的摘要数据类型和纯函数。函数接收 CSV 行、住宅类型、选中城市、起止月份，返回按选中城市顺序和住宅类型户型顺序排列的摘要行。该函数负责筛选原始数据、定位最新/月前/去年同月记录、计算基期累计涨幅；不负责 JSX 或样式。

摘要行至少包含：稳定 key、城市、户型、最新月份、环比原始指数、同比原始指数、基期涨幅。缺失值用 `null` 表示，由展示层格式化为 `—`。

### `src/components/SummaryTable.tsx`

新增表格组件，接收摘要行、住宅类型和实际基期月份。组件只负责语义化表格结构、动态列标题、数值格式化和空数据状态，不重新计算数据。

### `src/App.tsx`

基于已加载的原始 CSV 和现有 `effectiveFilters` 计算摘要行，并将摘要表渲染在趋势图容器之后、看板 footer 之前。加载失败、加载中、日期范围无效或未选城市时不输出误导性数据；有效但无摘要数据时显示现有空状态风格。

### `src/styles.css`

新增桌面端摘要表样式，延续现有卡片、边框、字体和颜色变量。不得新增移动端布局、断点或交互要求。

## 交互与状态

- 切换住宅类型时，表格跟随有效日期边界和户型集合更新。
- 增删城市时，表格行实时增删并保持选中城市顺序。
- 调整日期范围时，表格的最新月份、原始指标、基期月份和累计涨幅实时重算。
- 表格不提供独立筛选器，不引入新的图表库或外部依赖。

## 测试与验收

在 `tests/data.test.ts` 增加纯数据函数测试，至少覆盖：

- 二手住宅按城市生成一行，并读取最新环比和同比原始指数。
- 新建住宅按城市和三种户型生成三行。
- 指定起始月份后，基期涨幅按环比指数连乘计算。
- 指定起止月份后，最新月份严格落在包含边界的筛选区间内。
- 缺少上月或去年同月时返回 `null`，而不是借用其他月份。

实现后运行 `npm test` 和 `npm run build`；除本功能新增测试外，既有趋势计算测试必须继续通过。
