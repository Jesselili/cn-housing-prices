# 响应式图表宽度设计

## 目标

当图表数据较少时，让图表填满所在卡片的可用内容宽度；当数据点较多、标签或柱体需要更大间距时，保持数据点的最小展示宽度并由外层容器提供横向滚动。

## 适用范围

- 房价趋势图：按月份数量计算最小月份槽宽。
- 市场广度趋势：按月份数量计算最小柱体槽宽。
- 最新环比图：按城市数量计算最小城市槽宽。
- 70 城横向比较是表格，不改变现有最小表格宽度和滚动行为。

## 实现方案

三个图表分别通过 `ResizeObserver` 读取各自滚动视口的可用宽度。每个图表的 SVG 宽度取“可用宽度”和“数据点数量乘以该图表的最小槽宽加图表边距”中的较大值。这样少量数据会拉伸到卡片宽度，长期月份和 70 城数据会保留足够的水平间距，超出视口时仍由已有滚动容器承载。

宽度计算保持为纯函数，组件只负责测量容器并把结果传给计算函数；不引入图表库，也不改变数据、排序、坐标轴口径或交互逻辑。首次测量完成前使用数据密度计算出的安全宽度，避免渲染出零宽图表。

## 验证标准

- 少量点位时，计算结果等于可用宽度。
- 点位较多时，计算结果不小于最小槽宽所需的内容宽度。
- 趋势图、市场广度图、最新环比图都使用容器测量结果。
- `70 城横向比较` 的表格滚动和最小宽度不变。
- 现有测试、生产构建和差异检查通过。
