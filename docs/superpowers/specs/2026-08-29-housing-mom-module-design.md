# 70 城价格指数环比模块设计

## 目标

在现有趋势看板之后增加一个独立的环比模块，固定展示当前 CSV 最新月份的全部可用城市，不读取上方趋势看板的城市选择和日期范围。模块支持二手住宅和新建住宅两类视图，并用柱状图呈现各城市当月环比变化。

## 用户可见结果

模块标题格式为：

- 二手住宅：`70 城价格指数环比-二手住宅-202607`
- 新建住宅：`70 城价格指数环比-新建住宅-90m²及以下-202607`

标题中的月份使用当前数据的最新有效月份，格式为 `YYYYMM`。新建住宅标题包含当前户型，避免切换户型后口径不明确。

概览区域展示：

- 覆盖城市
- 上涨
- 持平
- 下降
- 均值
- 区间

截图中的“中位数”不纳入本次需求，因为文字需求未指定该字段。

## 数据口径

- 二手住宅使用 `house_type=二手住宅`、`size_band=全部`。
- 新建住宅使用 `house_type=新建商品住宅`，默认 `size_band=90m2及以下`，可切换到 `90-144m2` 和 `144m2以上`。
- 只使用 `metric=环比`、`base=上月=100` 的原始 `value`。
- 每个城市的环比变化为 `value - 100`，例如 `96.7` 显示为 `-3.3%`。
- 上涨为变化值大于 0，持平为等于 0，下降为小于 0；原始数据保留 1 位小数，因此按当前存储值判断，不自行设置模糊阈值。
- 覆盖城市为最新月份内具有有效环比值的去重城市数。
- 均值为所有有效城市变化值的算术平均值。
- 区间为所有有效城市变化值的最小值和最大值。
- 概览和柱顶数值统一显示 1 位小数，并为正值增加 `+` 号。

## 排序与分组

柱状图按环比变化从高到低排序，同值时按城市名称稳定排序。第一版不区分一线、二线、三线，也不提供对应筛选。

原因是城市等级并非 CSV 的统计字段，不同机构的分级名单和更新时间可能不同；如果没有明确来源和生效日期，分组会制造虚假的精确性。70 城横向展示通过固定柱槽宽和横向滚动解决，不用城市等级作为布局补偿。

## 架构

### `src/data.ts`

新增纯函数和数据类型，用于从原始 CSV 计算最新月份的环比快照。函数接收住宅类型和新建住宅户型，返回最新月份、排序后的城市数据和概览统计；不依赖上方筛选状态，不负责 JSX 或样式。

### `src/components/MonthOverMonthModule.tsx`

新增独立模块组件，内部管理住宅类型和新建住宅户型状态。二手住宅默认视图固定为 `全部`；切换新建住宅时默认选中 `90m²及以下`。组件负责标题、概览卡、控制项和柱状图布局，但不重新计算统计数据。

### `src/App.tsx`

在现有趋势看板之后渲染独立环比模块，并传入已加载的原始 CSV。该模块不接收上方城市选择和日期范围作为数据筛选条件。

### `src/styles.css`

新增环比模块的桌面端卡片、概览、控件和 SVG 柱状图样式。柱状图使用足够的内部宽度和横向滚动容器容纳 70 个城市；不新增移动端断点或移动端专用交互。

## 交互与状态

- 环比模块加载数据后自动显示最新月份。
- 切换二手住宅/新建住宅时重新计算概览和柱状图。
- 新建住宅切换户型时重新计算概览和柱状图。
- 上方趋势看板的城市、日期范围变化不影响本模块。
- 数据加载失败时显示模块级错误/空状态，不渲染猜测数据。
- 如果未来最新月份数据不完整，标题仍显示实际最新月份，覆盖城市显示实际有效城市数。

## 测试与验收

在 `tests/data.test.ts` 增加纯数据函数测试，至少覆盖：

- 最新月份识别和仅纳入环比/上月=100 数据。
- 二手住宅 `全部` 口径输出所有有效城市。
- 新建住宅三种户型的切换口径。
- 按变化值降序排序和同值稳定排序。
- 上涨、持平、下降计数。
- 均值和区间计算。
- 空值和非数字值被排除。

为 `MonthOverMonthModule` 增加静态渲染测试，覆盖动态标题、概览字段、户型文案、柱状图城市标签和正负值格式。

实现后运行 `npm test` 和 `npm run build`。既有趋势图、日期范围和摘要表测试必须继续通过。

## 约束

- 不读取、复制或修改 `examples/`。
- 保持 React + TypeScript + Vite 技术栈。
- 图表使用原生 SVG，不引入图表库。
- 不改变现有趋势图的累计指数口径。
- 不把一二三线城市分级写入数据或默认 UI。
