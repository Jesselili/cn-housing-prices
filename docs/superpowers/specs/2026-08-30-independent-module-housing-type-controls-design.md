# 独立模块住宅类型筛选设计

## 目标

将住宅类型筛选从页面级联动改为按模块独立控制：房价趋势模块的切换只影响房价趋势及其最新数据摘要，70 城横向比较和市场广度趋势分别拥有自己的住宅类型切换。

## 已确认的交互

- 房价趋势模块保留现有页面级「二手住宅 / 新建住宅」切换。
- 70 城横向比较在模块标题栏增加独立切换，默认显示二手住宅。
- 市场广度趋势在模块标题栏增加独立切换，默认显示二手住宅。
- 两个新增切换互不影响房价趋势模块，也互不影响彼此。
- 新建住宅面积段筛选继续保留在各自模块内，只影响当前模块。
- 最新环比模块不纳入本次改动。

## 实现方案

`App` 继续持有趋势图所需的 `filters.housingType`，并将该状态用于趋势图、摘要表、可用日期范围和趋势状态信息。`CityComparisonMatrix` 与 `MarketBreadthModule` 不再接收 `housingType` 属性，而是在组件内部分别维护以「二手住宅」为初始值的住宅类型状态。组件内部的数据快照计算和标题文本都改为使用各自的本地状态。

两个模块都复用现有住宅类型常量和分段按钮视觉模式；新建住宅时继续显示并使用本模块自己的面积段状态。这样不引入全局状态，也不改变数据计算规则。

## 验证范围

- 组件渲染结果包含独立的「二手住宅 / 新建住宅」按钮，且初始按钮状态为二手住宅。
- `App` 不再向两个独立模块传递趋势模块的 `housingType`。
- TypeScript 构建通过，现有数据计算测试和组件测试通过。
