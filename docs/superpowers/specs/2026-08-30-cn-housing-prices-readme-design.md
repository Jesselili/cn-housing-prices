# cn-housing-prices README 设计

## 目标

为仓库首页补充一份与当前实现一致的中文 README，让读者无需先阅读源码即可理解项目用途、技术方案、数据来源、计算口径、运行方式和当前限制。

本次只补充项目文档，不新增产品功能，不改变数据处理逻辑，不修改 `examples/`（当前仓库没有该目录）。

## 文档结构

README 按以下顺序组织：

1. 项目介绍：说明这是一个桌面优先的中国房产趋势看板，展示国家统计局 70 城住宅价格指数和 LPR 融资成本背景数据。
2. 当前功能：介绍趋势图、城市筛选、时间范围、显示模式、汇总表、城市横向比较、市场广度、最新月环比快照、数据状态和 LPR 模块。
3. 技术方案：说明 React + TypeScript + Vite、原生 SVG、浏览器端 CSV 加载、`src/data.ts` 的纯数据处理边界、组件自主状态和 `ResizeObserver` 自适应图表宽度。
4. 数据来源与目录：列出 `data/house_price_index_all.csv`、`data/LPR.csv`、核心源码目录和测试目录；不把脚本或 README 中未验证的生成文件写成现有数据文件。
5. 数据口径：分别说明房价指数和 LPR 的字段筛选、房屋类型/面积段、趋势图归一与连乘、原始环比快照、同比和多周期复合变化、市场广度统计、缺失月份处理，以及“价格指数不等于每平方米房价”。
6. 数据范围与限制：说明覆盖范围由当前 CSV 决定，城市或月份缺失会在状态区展示；房价模块不提供绝对成交单价；LPR 是融资成本参考指标，不能单独解释房价变化。
7. 本地运行：提供依赖安装、测试、构建、开发服务和预览命令。
8. 发布与回滚：引用现有 `VERSIONING.md`，说明稳定分支和版本标签约定，不重复维护另一套 Git 流程。

## 关键口径

- 房价运行数据只认 `data/house_price_index_all.csv`。
- 房价筛选使用 `metric=环比`、`base=上月=100`。
- 二手住宅使用 `size_band=全部`；新建商品住宅使用 `90m2及以下`、`90-144m2`、`144m2以上`。
- 趋势图先按城市、房屋类型和日期范围筛选原始行，再将选定范围内每条序列的首个有效月归一为 100，后续按月度环比指数连乘；它是累计指数趋势，不是绝对房价曲线，也不是单月环比曲线。
- 最新月环比、市场广度和相关快照使用原始月度环比行，不复用趋势图的城市和日期筛选。
- 汇总表展示最新月环比、同比和相对基期的累计增长；城市比较矩阵额外展示 1 年、3 年和 5 年复合变化，缺少足够历史数据时保留为空。
- LPR 独立读取 `data/LPR.csv`，展示 1 年期和 5 年期利率；5 年期更接近长期住房贷款观察场景，但 LPR 不直接决定房价。
- 缺失整月与城市局部缺失分开说明，不能把整月缺失重复计入城市缺失。

## 数据流与模块边界

浏览器加载两份静态 CSV 后，`src/data.ts` 负责解析、筛选、归一化、复合计算和摘要生成；`App` 管理趋势域的数据加载和筛选状态；趋势图与汇总表共享趋势筛选；城市比较、市场广度、最新月环比各自维护独立的房屋类型/面积段控制；LPR 模块保持独立，不接收房价筛选器。

## 验收标准

- README 的每项描述都能在当前源码、当前 CSV 或 `AGENTS.md` 中找到依据。
- README 不把价格指数描述为绝对房价，不混淆累计指数与单月环比，不混淆 LPR 与房价。
- `npm test` 和 `npm run build` 通过。
- 同步远端前先检查远端最新状态；保留当前工作区改动，避免覆盖用户修改。
- 完成后将 README、设计文档和当前工作区已有代码/测试改动提交到 `main`，推送到 `origin/main`，并用远端提交记录确认推送成功。
