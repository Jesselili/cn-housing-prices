# 房价数据状态与指标显示切换设计

## 目标

在现有房价趋势 dashboard 中加入两个能力：

1. 动态数据状态卡：让用户知道当前数据更新到哪里、覆盖范围如何、数据来自哪里。
2. 指数 / 变化率切换：让趋势图和摘要表可以直接阅读“指数值”或“相对变化率”，不要求用户自行减去 100。

## 范围

- 数据状态卡只使用当前已加载的 `data/house_price_index_all.csv`，不新增外部数据源。
- 最新月份、城市覆盖数、各住房类型的数据范围和整月缺失月份均由 CSV 动态计算。
- 来源链接使用最新月份对应记录中的 `source_url`，链接文案显示“国家统计局原始页面”。
- 更新时间显示浏览器成功读取 CSV 的本地时间，并标注“页面读取时间”；不把页面读取时间当作数据发布日期。
- 指标切换影响主趋势图和主摘要表，不影响独立的“最新环比”模块。
- 默认显示当前已有的指数模式。
- 指数模式：趋势图显示以所选范围首个有效月归一为 100 的累计指数；摘要表显示原始环比/同比指数和累计变化百分比。
- 变化率模式：趋势图显示相对所选范围首个有效月的累计变化率；摘要表将环比、同比和累计变化统一显示为百分比。
- 不改变原始数据过滤、归一化、环比连乘和缺失值处理规则。

## 页面结构

`DashboardIntro` 下方新增 `DataStatusCard`，在主趋势卡之前展示：

- 最新数据月份；
- 覆盖城市数（全数据集，格式为 `70 / 70 个城市`，若数据不足则按实际值显示）；
- 二手住宅和新建商品住宅的数据范围；
- 各住房类型的整月缺失月份数量；
- 最新数据来源链接；
- 页面读取时间。

主趋势卡控件区域新增 `MetricDisplayToggle`，选项为“指数”和“变化率”。该状态由 `App` 持有，并传给 `TrendChart` 与 `SummaryTable`。

## 数据接口

新增 `MetricDisplayMode = 'index' | 'change'`。

新增 `DataStatus`，至少包含：

```ts
interface DataStatus {
  latestPeriod: string | null;
  cityCount: number;
  expectedCityCount: number;
  housingTypes: Record<HousingType, {
    firstPeriod: string | null;
    latestPeriod: string | null;
    missingPeriods: string[];
  }>;
  sourceUrl: string | null;
  loadedAt: Date | null;
}
```

新增 `getDataStatus(rows, loadedAt)`，根据有效的环比、`上月=100` 数据计算状态。某个住房类型的完整可用月份集合取该类型的有效月份；整月缺失月份以全体数据的月份范围为参照计算。城市覆盖数按所有有效房价记录中的唯一城市计算。

新增 `formatDisplayValue(value, mode)`，用于将指数或累计指数转成展示值：

- `index`：保留两位小数；
- `change`：计算 `value - 100`，显示正负号并保留两位小数，附 `%`。

摘要表继续保存原始数值，但根据 `mode` 选择格式化方式：环比/同比在变化率模式显示 `value - 100`；累计涨幅仍使用现有 `baseGrowth`，避免重复连乘。

## 错误与空数据

- CSV 加载失败时，状态卡显示“数据状态暂不可用”，不显示虚假的更新时间或来源链接。
- 没有有效记录时，所有状态字段显示“暂无数据”。
- `source_url` 缺失时显示“暂无来源链接”。
- 读取时间在 CSV 请求成功且完成解析后记录；页面重新加载时重新生成。
