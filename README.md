# 中国房产趋势看板

一个桌面优先的中国房产趋势分析看板。项目基于国家统计局公开的 70 城住宅价格指数，配合 LPR（贷款市场报价利率）数据，帮助观察城市房价指数的月度变化、阶段性趋势、城市差异和融资成本背景。

> 重要说明：本项目展示的是价格指数，不是每平方米成交单价。指数可以用来观察相对变化，但不能直接当作房价水平或房屋估值。

## 项目功能

- 房价趋势：查看北京、上海、广州、深圳、长沙等城市的二手住宅或新建商品住宅趋势。
- 趋势筛选：按城市、住宅类型和起止月份筛选；城市选择支持搜索，已选城市会保留在筛选区。
- 显示模式：在原始指数和相对基期变化率之间切换。
- 最新数据摘要：查看选定城市的最新月份、环比、同比和选定基期以来的累计变化。
- 城市比较：独立比较全部可用城市的最新环比、同比，以及近 1 年、3 年、5 年累计变化，并支持排序。
- 市场广度：按月份统计上涨、持平和下降城市数量，观察市场变化的广泛程度。
- 最新月环比快照：按最新可用月份展示全部城市的环比排名和上涨/持平/下降概览。
- 数据状态：展示数据加载状态、覆盖范围、整月缺失和城市局部缺失。
- LPR 趋势：独立展示 1 年期和 5 年期 LPR，5 年期作为长期住房贷款融资成本的重点观察指标。

## 技术方案

### 技术栈

- React 19
- TypeScript
- Vite
- Vitest
- 原生 SVG 图表
- 浏览器端加载静态 CSV

项目不依赖图表库。图表由原生 SVG 绘制，趋势图、市场广度、最新月环比和 LPR 图表根据容器宽度使用 `ResizeObserver` 调整布局；数据点较密集时保留最小点位宽度，并通过横向滚动查看。

### 数据流

浏览器分别加载两份静态数据文件：

1. `/data/house_price_index_all.csv`：房价指数数据；
2. `/data/LPR.csv`：LPR 数据。

`src/data.ts` 负责 CSV 解析、原始行筛选、日期范围处理、指数归一化、累计计算、摘要生成和数据覆盖检查。页面组件主要负责交互状态和语义化渲染。

趋势域的筛选状态由 `App` 管理，趋势图和最新数据摘要共享住宅类型、城市和日期范围。城市比较、市场广度、最新月环比三个模块各自维护住宅类型和新建住宅面积段控制，不受趋势图的城市和日期筛选影响。LPR 是独立的数据域，不接收房价筛选器。

## 数据来源与文件

### 房价指数

运行时读取：

```text
data/house_price_index_all.csv
```

当前本地数据快照：

- 170,584 行；
- 70 个城市；
- 房价数据期间：`2011-02—2026-07`；
- 包含二手住宅、新建商品住宅，以及不同面积段；
- CSV 中保留原始指标字段、变化字段和来源链接。

房价 CSV 的主要字段包括：

| 字段 | 含义 |
| --- | --- |
| `period` | 月份，格式为 `YYYY-MM` |
| `house_type` | 住宅类型 |
| `size_band` | 面积段 |
| `city` | 城市 |
| `metric` | 指标类型，如环比、同比、累计平均 |
| `base` | 比较基期 |
| `value` | 指数值 |
| `change_pct` | 原始变化字段 |
| `source_url` | 数据来源链接 |

### LPR

运行时读取：

```text
data/LPR.csv
```

当前本地数据快照：

- 85 条发布日期记录；
- 发布日期期间：`2019-08-20—2026-08-20`；
- 字段为发布日期、1 年期 LPR 利率和 5 年期 LPR 利率；
- 页面保留中国人民银行 LPR 来源链接。

LPR 是银行贷款定价的参考利率和融资成本指标，不是房价。LPR 下调可能降低部分借款人的利息负担，但不能单独推出房价必然上涨或购房需求必然回升。

## 数据口径

### 房价趋势的筛选口径

房价趋势、城市比较、市场广度和最新月环比模块使用房价 CSV 中满足以下条件的原始行：

```text
metric = 环比
base = 上月=100
```

住宅类型与面积段规则如下：

| 住宅类型 | 使用的 `size_band` |
| --- | --- |
| 二手住宅 | `全部` |
| 新建商品住宅 | `90m2及以下`、`90-144m2`、`144m2以上` |

页面展示标签会将面积单位显示为 `m²`，CSV 内部字段保持原始命名。

### 趋势图的累计指数

趋势图先筛选原始行，再对每条城市/面积段序列处理：

1. 选定范围内的第一个有效月份归一为 100；
2. 后续月份按原始环比指数逐月连乘；
3. 得到选定范围内的累计指数趋势。

例如，原始环比指数为 `96.7`，表示该月相较上月约下降 3.3%。但如果趋势图显示 `96.7`，它表示相较当前所选范围的基期累计下降约 3.3%，不能直接理解为该月单月下降 3.3%。

因此：

- `100` 表示相对相应比较基期或选定趋势基期没有变化；
- 高于 100 表示相对基期累计上涨；
- 低于 100 表示相对基期累计下跌；
- 这些数值都是指数，不是元/平方米。

日期范围采用包含起止月份的规则。默认使用 CSV 的完整可用范围；如果选择了住宅类型或城市，日期选择器会根据对应数据重新计算可用月份。缺失月份不会被插值填补，图表和数据状态会保留缺失信息。

### 摘要表

摘要表跟随趋势图的住宅类型、城市和日期范围：

- 环比：使用最新月份的 `环比 + 上月=100` 原始指数；
- 同比：使用最新月份的 `同比 + 上年同月=100` 原始指数；
- 基期累计变化：对选定日期范围内的月度环比指数进行连乘，换算为相对基期的变化率；
- 显示模式只改变展示方式，不改变底层数据计算。

### 城市比较矩阵

城市比较矩阵独立使用全部可用城市和最新可用月份：

- 最新环比：最新月份的原始环比指数减 100；
- 最新同比：最新月份的原始同比指数减 100；
- 近 1 年、近 3 年、近 5 年累计：分别对相应月份窗口内的环比指数连乘后减 100；
- 历史数据不足时显示为空，不用短数据窗口替代完整窗口；
- 新建商品住宅可以独立切换三个面积段。

### 市场广度与最新月环比

市场广度按每个月有有效数据的城市统计：

- 上涨：环比指数大于 100；
- 持平：环比指数等于 100；
- 下降：环比指数小于 100；
- 覆盖城市数以该月份实际有有效数据的城市数为准。

最新月环比快照使用全部可用城市的最新有效月份，按原始环比变化率从高到低排序；它不使用趋势图的城市选择和日期范围。

### 缺失数据

数据状态区分两类情况：

- 整月缺失：在整体覆盖期间内没有任何合格房价数据的月份；
- 城市局部缺失：某个城市缺少数据，但该月份仍有其他城市数据。

整月缺失不会重复计入城市局部缺失。覆盖范围和缺失说明由当前 CSV 动态计算。

## 项目限制

- 价格指数不等于绝对房价，也不提供每平方米成交单价。
- 70 城指数适合观察相对趋势和城市间变化，不应直接用于估算具体小区、房屋或个人资产价值。
- 趋势图的累计指数依赖所选基期；更换日期范围后，首个有效月会重新归一为 100，不同基期的数值不能直接混读。
- LPR 只能作为融资成本背景，不能单独解释房价变化；实际房贷利率还取决于合同、加点和重定价日。
- 当前覆盖范围取决于仓库中的 CSV 快照，数据文件更新后，页面范围和数据状态会随之变化。
- 静态部署时需要把 `data/` 目录作为可访问的静态资源发布，因为页面通过 `/data/house_price_index_all.csv` 和 `/data/LPR.csv` 请求数据。

## 本地开发

需要 Node.js 和 npm。

```bash
npm install
npm run dev
```

开发服务启动后，按终端提示打开本地地址。

运行测试：

```bash
npm test
```

执行生产构建：

```bash
npm run build
```

本地预览生产构建：

```bash
npm run preview
```
